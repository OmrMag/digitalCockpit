About agent tokens
Agent tokens are API credentials used by the cockpit-agent — a small program that runs on your laptop and downloads scheduler outputs to local folders you configure per shard. Each token is tied to your account and grants the agent the ability to fetch your runs.
Create one token per laptop you want files delivered to. Paste the token into the agent's config file once. The plaintext is shown only once after creation — store it somewhere safe.
Security: a token grants read access to your run records and output files. If a token is exposed, revoke it immediately — that invalidates it instantly. Tokens never let an agent log in to the cockpit UI or modify anything.
